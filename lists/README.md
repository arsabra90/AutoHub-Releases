# Auto Hub lists · قوائم أوتو هب

The channel and station lists the app loads by default (it reads them from this branch, so they can be updated without a new app version).

- `tv.m3u`: the TV channels, in order, with their groups (60 channels, picked from iptv-org's Arabic, Saudi and Egyptian lists).
- `radio.json`: the radio stations, in order, with their groups (picked from Radio Browser).

القوائم التي يحمّلها التطبيق افتراضياً: قنوات التلفاز ومحطات الراديو المختارة بمجموعاتها وترتيبها.
